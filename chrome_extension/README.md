An enterprise-grade Chrome extension that injects an **autonomous AI healing copilot** directly into the GitHub Actions interface.

## 🚀 Quick Setup (30 Seconds)

1. Open Google Chrome (or Brave / Microsoft Edge).
2. In the address bar, navigate to:
   ```
   chrome://extensions/
   ```
3. In the top-right corner, toggle **Developer mode** to **ON**.
4. Click the button in the top-left: **Load unpacked**.
5. Select this folder:
   ```
   C:\Users\Jatin\Desktop\Devops\chrome_extension
   ```
6. Done! The **AutoHeal CI/CD** extension icon will now appear in your browser toolbar!
